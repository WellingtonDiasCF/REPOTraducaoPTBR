# Tradução PT-BR para R.E.P.O.

Tradução contextual do R.E.P.O. para português do Brasil, incluindo menus, HUD, itens, objetivos e textos que não fazem parte das tabelas normais do jogo.

## Instalação

Clique em **Install with Mod Manager** e abra o jogo pelo botão **Modded** do Thunderstore Mod Manager, r2modman ou Gale.

O BepInEx será instalado automaticamente. Este pacote mantém as tabelas dentro do perfil do gerenciador e não substitui os arquivos originais do jogo.

## Recursos

- Tradução PT-BR para menus, HUD, textos da partida, itens e objetivos.
- Tratamento contextual de textos fixos e de interfaces de mods.
- Instalação isolada compatível com perfis de gerenciadores.
- Textos ainda não traduzidos são registrados em `BepInEx/config/RepoPTBRContextual.missing.tsv` para ajudar nas próximas versões.
- Nenhuma configuração é necessária.

A tradução funciona somente no computador em que está instalada. Em partidas multiplayer, cada pessoa que quiser os textos em português precisa instalar o pacote; isso não afeta o host nem os outros jogadores.

## Depois de uma atualização

Se o R.E.P.O. alterar ou adicionar textos, algumas partes podem permanecer temporariamente em inglês. Procure uma atualização no Thunderstore antes de relatar o problema.

## English

A contextual Brazilian Portuguese translation for R.E.P.O. It covers the main game localization tables and additional hardcoded interface strings handled by the included plugin.

Use **Install with Mod Manager**, then launch R.E.P.O. with the **Modded** button in Thunderstore Mod Manager, r2modman, or Gale. BepInEx is installed automatically and the original game files remain untouched.

The translation is client-side. In multiplayer, each person who wants Portuguese text must install the package on their own PC.

## Alternative installer

Um instalador independente para Windows e instruções manuais estão disponíveis no [GitHub](https://github.com/WellingtonDiasCF/REPOTraducaoPTBR). A instalação pelo Thunderstore é recomendada para quem já usa um gerenciador de mods.

## Support

Relate problemas reproduzíveis no [GitHub](https://github.com/WellingtonDiasCF/REPOTraducaoPTBR/issues). Inclua a versão do jogo, uma captura do texto não traduzido e o arquivo `BepInEx/LogOutput.log`, quando possível.
