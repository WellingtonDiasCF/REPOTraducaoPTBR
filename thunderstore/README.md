# R.E.P.O. Brazilian Portuguese Translation

A contextual Brazilian Portuguese translation for R.E.P.O. It covers the main game localization tables and additional hardcoded interface strings handled by the included plugin.

## Installation

Use **Install with Mod Manager** on Thunderstore, then launch R.E.P.O. with the **Modded** button in Thunderstore Mod Manager, r2modman, or Gale.

The BepInEx dependency is installed automatically. This package keeps its translation tables inside the mod profile and does not replace the original game files.

## Features

- Brazilian Portuguese translation for menus, HUD, gameplay text, items, and objectives.
- Contextual handling for hardcoded and modded interface strings.
- Isolated installation compatible with mod-manager profiles.
- Missing user-facing strings are recorded in `BepInEx/config/RepoPTBRContextual.missing.tsv` to help future updates.
- No configuration is required.

The translation is client-side. In multiplayer, each person who wants Portuguese text must install the package on their own PC; it does not affect the host or other players.

## After a game update

If R.E.P.O. changes or adds text, some entries may temporarily remain in English. Check Thunderstore for an updated package before reporting the problem.

## Português

Tradução contextual do R.E.P.O. para português do Brasil, incluindo menus, HUD, itens, objetivos e textos que não fazem parte das tabelas normais do jogo.

Clique em **Install with Mod Manager** e abra o jogo pelo botão **Modded** do Thunderstore Mod Manager, r2modman ou Gale. O BepInEx será instalado automaticamente e os arquivos originais do jogo não serão substituídos.

A tradução funciona somente no computador em que está instalada. Em partidas multiplayer, cada pessoa que quiser os textos em português precisa instalar o pacote.

## Alternative installer

An independent Windows installer and manual instructions are available on [GitHub](https://github.com/WellingtonDiasCF/REPOTraducaoPTBR). The Thunderstore installation is recommended for people who already use a mod manager.

## Support

Report reproducible issues on the [GitHub issue tracker](https://github.com/WellingtonDiasCF/REPOTraducaoPTBR/issues). Include the game version, a screenshot of the untranslated text, and `BepInEx/LogOutput.log` when possible.
